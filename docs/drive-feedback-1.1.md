# 1.1の広告教材・広告表示・ストア素材

## 教材の出題と採点

「おすすめの練習」の初回は、広告と最終確認画面の条件が一致する問題、その画面だけでは次回請求が分からない問題、表示が矛盾する問題の順。結果画面では根拠・理由・次の確認を同じ順に示す。正解位置は択一の2番目・1番目、箇所選択の2番目・4番目。ひらがな表示も同じ意味になるよう個別に記載した。

公開中の従来の無料50問では、旧ニュース10問すべての正解が4番目、旧広告10問すべてで3・4番目が正解に含まれていた。1.1では旧ニュースの提示位置を2番目5問・3番目4問・4番目1問に分け、旧広告でも一部を前後に動かした。旧版の配信や正解IDは維持し、表示・読み上げ・解説の順をそろえる。期限があるだけの文を誤りとする旧広告2問は、1.1で旧版のまま届いた場合は新たに出題しない。

## 広告と購入の配信確認

無料版で導入3問を終え、その後の初挑戦を3問終えた結果画面に1枠を出す。やり直し・お手本は数えない。無料であることをStoreKitで確認できない間と、購入・復元中、購入済みでは表示しない。広告リクエストはGoogleの同意管理が許可した場合に限り、子供向け取り扱い・一般向け広告区分・パーソナライズ無効を設定する。シミュレータとDebugビルドはテスト用広告IDを使う。

1. 無料で導入の解説に広告がないこと、以後のセット終了に1件だけ表示されることを確認する。広告の表示と採点・次の操作は分かれていることを確認する。
2. 広告の報告を開き、表示時刻と広告確認番号を確認する。受け取った報告と時刻・画像などをAdMobの広告レビューセンターで照合し、対象広告をブロックする。テスト広告をクリックして本番の配信確認を代替しない。
3. 同じビルドで購入・復元し、広告が消えること、通常の追加問題と現実モードを切り替えられることをSandboxと実機で確認する。返金後も確認する。
4. 購入画面の価格はStoreKitの表示価格、買い切りと復元の導線を確認する。件数は `premium-summary` が返す配信中の通常・現実モード件数。概要のレスポンスに本文・正解・保存場所がないことと、購入証明なしでは本体を取得できないことを確かめる。
5. AdMobで既存の広告枠と同意メッセージ、年齢区分・ブロックの設定を確認し、署名済み本番ビルドで広告配信結果を確認する。App Store Connectのプライバシー申告は実際のSDK設定・アーカイブのプライバシーレポート・公開ポリシー案と照合する。

## ストアと利用後の確認

最初の3枚は「出題」「根拠を選ぶ」「解説」。日本語のリソースを含む提出ビルドで、App Storeの言語欄が日本語になることを確認する。既存の掲載内容や公開中の広告設定は別途確認のうえ切り替える。

試用では、Aで期限だけを理由に誤警戒した人数、Cで表示の矛盾を見落とした人数、別のお試し商品で確認すべき箇所を説明できた人数を、回答者数と併記する。氏名やメールアドレスは記録しない。

App Store Connectでは、変更前後で同じ日数・ストア地域・端末区分を選ぶ。表示回数、製品ページ閲覧数、初回ダウンロードを同じ期間で記録し、閲覧数÷表示回数、初回ダウンロード÷製品ページ閲覧数を参考にする。閲覧とダウンロードは同一利用者を追った数値ではないため、比率の前後差だけで原因を断定しない。
