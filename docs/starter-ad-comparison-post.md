# 投稿原稿：同じ「お試し980円」でも、どこが違う？

二つとも、広告の見出しは「お試し980円、日曜まで。」。注文を確定する前に、どちらの表示で食い違いが見つかるでしょう？

| | A | B |
| --- | --- | --- |
| 広告の条件 | 単品、税込980円、送料込み。次の請求なし | 980円で1回だけ。次の商品は自動では届かない |
| 最終確認画面 | 単品、税込980円、送料込み。次の請求なし | 初回980円。2回目から3,980円。毎月自動で届く |

答え：**B**。広告の「1回だけ」と、確認画面の「毎月自動で届く」が食い違います。初回の金額が同じでも、注文を確定せず、次に届くかと次の金額を確認しましょう。

Aには総額と次回請求の有無が示されています。日曜までという期限だけで、問題があるとは決められません。

※ミヌクルの練習用に作った架空の広告です。実際の購入案内ではありません。
