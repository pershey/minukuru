# 学習体験・アクセシビリティ・課金配信の再点検

## 維持する実装

- SwiftUI / MVVM、iOS 17以上、ローカル問題とSupabase配信のフォールバックを維持する。
- 買い切り商品`com.naoyaochiai.minukuru.premium`と、StoreKitが返す地域別価格表示を維持する。
- 問題ID、UserDefaultsの回答履歴、無料50問、プレミアムの追加問題・実施済みスキップ・現実モードを維持する。
- ひらがな表示、Dynamic Type、色以外の選択表示、44pt以上の操作領域を土台として活用する。

## 調査結果と対応

| 優先度 | 根拠となる画面・ファイル | 利用者への影響 | 対応 |
| --- | --- | --- | --- |
| P0 | `content-manifest` / `content-manifest-v2` | 画面を隠すだけでは有料問題を保護できず、購入時JWSだけでは後日の返金状態を再確認できない | v2でApple署名、商品ID、bundle ID、現在の取引状態を検証する。移行後は旧endpointを無料専用にする |
| P1 | `QuizView` / `QuizSessionViewModel` | 怪しい箇所と理由を同時に選ぶため、何を考える手順なのか分かりにくい | 箇所選択と理由選択を2段階に分け、理由は最も近い1つを選ぶ |
| P1 | 旧`QuizQuestion` / `QuizScorer` | 「分からない」と「この情報では判断できない」、「問題なし」と「絶対安全」を採点上区別できない | 単一選択回答と意味属性を追加し、判断材料不足・問題が見当たらない・次の行動を別回答として扱う |
| P1 | 旧`ResultView` | 正解箇所は見られるが、注目点・理由・次の行動の対応が弱い | 元の文章を残し、解説を「どこ・なぜ・次」の3項目で表示する |
| P1 | 旧履歴モデル | ヒント後や再挑戦の正解を初回自力正解と区別できない | `hintUsed`、`attemptNumber`、`learningStage`、`contentRevision`を後方互換で保存する |
| P1 | 旧クイズ画面 | 中断後に問題と現在の作業へ戻れない | 問題ID、回答段階、選択、ヒント利用をUserDefaultsへ保存し「続きから」を追加する |
| P1 | 問題・結果画面 | OSのVoiceOverは使えるが、長文を明示的に聞く・止める・聞き直す操作がない | AVSpeechSynthesizerで「読み上げる／停止／もう一度聞く」を追加する。標準VoiceOverは置き換えない |
| P2 | 旧モード選択 | 初回から5モードが同じ強さで並び、開始前の判断が多い | 「おすすめの練習」を主導線にし、モード一覧を折りたたむ |
| P2 | 旧クイズ画面の広告 | 学習中の注意を分散し、誤タップにつながる | 新規広告は追加せず、既存広告をモード選択末尾へ移す |

## 代表問題の方針

`learning_questions.json`に、子ども向け11問と大人向け3問を用意する。対象属性は学習内容の区分であり、
購入権限とは別に扱う。お手本、練習、行動、腕試しを含み、腕試しには「判断材料が不足」と
「問題のある表現は見当たらない」を含める。ひらがな表示用テキストは子ども向け問題に必須とする。

## 手動確認が必要な項目

- VoiceOverの実際の読み上げ順、スイッチコントロール、最大文字サイズでの操作感。
- 子どもと高齢者が、操作に迷わず、解説を自分の言葉で説明し、別の文章へ考え方を移せるか。
- TestFlight Sandboxでの購入、キャンセル、保留、失敗、復元、再起動後、返金後の状態。
- App Store Server API用Secretsを設定した検証環境で、premium取得が購入済みだけに許可されること。

対象者テストや学習効果の検証は、この実装・自動テストだけで実施済みとはしない。
